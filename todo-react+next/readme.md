#  Simple Todo App (React + Next.js)

A minimal Todo List application built using **React** and **Next.js (App Router)**.  
You can add, delete, and toggle tasks — all in a clean, responsive interface.

---

##  Features

- Add new todos  
- Mark todos as completed / uncompleted  
- Delete todos  
- Responsive and minimal design 
- Built on Next.js 14 (App Router)
##  Tech Stack
- **Frontend:** React (with Hooks)
- **Framework:** Next.js 14+
- **Language:** JavaScript (ES6+)
